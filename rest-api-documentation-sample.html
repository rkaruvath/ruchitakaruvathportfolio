REST API Documentation Sample

Reference documentation for the fictional Bookshelf API, which manages a library catalog.

Overview

The Bookshelf API is organized around REST. It uses JSON for requests and responses, and standard HTTP status codes. Authenticate by sending your API key in the Authorization header.

Base URL: https://api.example.com/v1

Get a book

GET/books/{book_id}

Returns a single book by its ID.

Parameters

NameInTypeRequiredDescription
book_idpathstringYesUnique book identifier.
expandquerystringNoSet to author to include author details.

Example request

curl -X GET "https://api.example.com/v1/books/bk_123?expand=author" \
  -H "Authorization: Bearer YOUR_API_KEY"

Example response

{
  "id": "bk_123",
  "title": "The Pragmatic Writer",
  "isbn": "978-0-00-000000-0",
  "available": true,
  "author": { "id": "au_45", "name": "Alex Rivera" }
}

Response codes

CodeMeaning
200The book was returned.
401The API key is missing or invalid.
404No book exists with that ID.
429Too many requests. Retry after the time in the Retry-After header.

Create a book

POST/books

Adds a book to the catalog. Send title and isbn in the JSON body. A successful call returns 201 with the new book.
