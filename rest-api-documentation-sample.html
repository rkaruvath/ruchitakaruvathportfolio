Change Management REST API

Use Change Management to plan, schedule, implement, and manage changes to the technology environment in your organization. For example, plan, schedule, and manage data migration tasks.

The Change Management API is organized around REST. It uses JSON for requests and responses, and standard HTTP status codes. Authenticate by sending your API key in the Authorization header.

Base URL: https://api.example.com/v1

Create a change request

POST/change

Request URL: <baseurl>/change

Request URL: <baseurl>/change

Creates a new change request.

Header parameters

NameDescription
AuthorizationAuthorization: Bearer
Content-Typeapplication/json

Request body parameters

NameTypeRequiredDescription
summarystringYesSummary for the change request.
impactintegerNoImpact of the change on the service level of the affected business processes.

The following are the supported values:

  • 1000: Extensive/Widespread
  • 2000: Significant/Large
  • 3000: Moderate/Limited
  • (Default) 4000: Minor/Localized
urgencyintegerNoUrgency measures how soon the change will significantly impact the business.

For example, a high-impact change may have low urgency if the impact is not expected to affect the business in the near future.

The following are the supported values:

  • 1000: Critical
  • 2000: High
  • 3000: Medium
  • (Default) 4000: Low
priorityintegerNoPriority is the relative importance of the change. Priority is based on the impact and urgency of the change.

The following are the supported values:

  • 1: Critical
  • 2: High
  • 3: Medium
  • (Default) 4: Low
risk levelintegerNoThe anticipated risk for the change.

For example, if a critical security update needs to be installed on all computers during business hours, the risk level can be 4 or 5. However, if it can be installed during non-business hours, the risk level can be 2.

The following are the supported values:

  • 1: Minimal (lowest risk)
  • 2: Low
  • 3: Medium
  • 4: High
  • 5: Extreme (highest risk)
statusintegerNoThe current state of the change request.

The following are the supported values:

  • (Default) 0: Draft
  • 1: Request For Authorization
  • 2: Planning In Progress
  • 3: Scheduled For Review
  • 4: Scheduled For Approval
  • 5: Scheduled
  • 6: Implementation In Progress
  • 7: Pending
  • 8: Rejected
  • 9: Completed
  • 10: Closed
  • 11: Cancelled
locationCompanystringNoThe location where the change needs to be implemented.
requestedFor.loginIdstringNoThe login ID of the user initiating the change request.
coordinator.loginIdstringNoThe login ID of the change coordinator to be assigned the change request.
changeManager.loginIdstringNoThe login ID of the change manager monitoring the change request.

Example request schema

{
    "summary": "Change created from API",
    "impact": 4000,
    "urgency": 1000,
    "status": 0,
    "locationCompany": "location_1",
    "requestedFor": {
        "loginId": "dev_1"
    },
    "coordinator": {
        "loginId": "coord_1"
    },
    "changeManager": {
        "loginId": "manager_1"
    }
}

Example request

curl -X POST "https://api.example.com/change" \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -d '{
    "summary": "Change created from API",
    "impact": 4000,
    "urgency": 1000,
    "status": 0,
    "locationCompany": "location_1",
    "requestedFor": {
      "loginId": "dev_1"
    },
    "coordinator": {
      "loginId": "coord_1"
    },
    "changeManager": {
      "loginId": "manager_1"
    }
  }'

Example response

If a change request is successfully created, the API returns an HTTP 201 Created status code with the following JSON object:

{
    "status": "Record created Successfully",
    "details": {
        "requestId": "CRQ000000000212",
        "guid": "AGGITSFNDMBO7AS40MSLS40MSLB3HN",
        "id": "CRQ000000000331"
    }
}

Status codes

Status codeDescription
201 CreatedThe resource is created successfully.
400 Bad requestOne or more fields contain invalid values.
403 UnauthorizedThe authentication credentials are incorrect or missing.
500 Internal server errorThe server encountered an unexpected error and couldn’t complete the request.

Show a change request

Request URL: /change/{id}

Shows a change request by ID.

Header parameters
