Sample: Connect a folder to SyncBox

Before you begin

You need a SyncBox account and version 2.4 or later of the desktop app.

Steps

  1. Open SyncBox and select Settings.
  2. Select Folders, then Add folder.
  3. Choose the folder you want to sync and select Connect.
  4. Wait for the status icon to show a green check mark.
NoteSyncing starts automatically. Large folders can take several minutes.
WarningDisconnecting a folder deletes its cloud copy after 30 days. Download any files you need first.

To check sync status from the command line, run:

syncbox status --folder ~/Documents
