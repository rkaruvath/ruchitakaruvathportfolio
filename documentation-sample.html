Enabling Agentic chat for ITSM

As an administrator, you can enable Agentic chat for the ITSM application. Agentic chat uses the advanced AI capabilities of GPT Manager to augment the global search, which is a full-text search in ITSM, with an AI-powered, chat-based search.

While working on incidents tickets in ITSM, service desk agents can use Agentic chat for a conversational, AI-driven experience to search for incident resolution information from knowledge articles. Instead of manually searching for information, service desk agents can ask specific questions in Agentic chat and get relevant, summarized answers. Thereby, leading to faster incident analysis and resolution.

To enable Agentic chat for ITSM

  1. In Mid Tier, open the AR System Configuration Generic UI form.
  2. Set the enableAgenticChat parameter to true.

To set the default search mode to Agentic chat or global search

After you enable Agentic chat, you can set the default search mode to Agentic chat or global search.

  1. In Mid Tier, open the AR System Configuration Generic UI form.
  2. Set the GlobalSearchDefaultMode parameter to one of the following options:
    • search: To set the default search mode to global search. The default value is search.
    • chat: To set the default search mode to Agentic chat.
